## Этапы работы:

1. Разверните проект и ознакомьтесь с кодом. Все необходимые вам компоненты уже созданы и лежат в папке `src/components`

2. Настройте роутинг.

3. Напишите функционал запросов данных с сервера, используя `Redux` и глобальный `store`. Сами "ручки" уже прописаны и лежат в `utils/burger-api.ts`

4. Настройте авторизацию и создайте защищённые роуты.

## Важно:

Для корректной работы запросов к серверу необходимо добавить переменную BURGER_API_URL в окружение. Сама ссылка находится в файле `.env.example`.

# Stellar Burgers

Современное React-приложение для заказа космических бургеров. Проект демонстрирует работу с продвинутыми концепциями фронтенд-разработки: централизованное управление состоянием, TypeScript и защищённые маршруты.

**[Посмотреть результат на GitHub Pages](https://oostap1985.github.io/stellar-burgers/)**

## 🛠 О проекте

Stellar Burgers — это одностраничное приложение (SPA), созданное на современном стеке технологий. Пользователи могут собирать свои бургеры перетаскиванием ингредиентов, оформлять заказы и отслеживать их статус в реальном времени. Особое внимание уделено архитектуре состояния приложения и типобезопасности.

## 🚀 Ключевые особенности реализации

*   **Управление состоянием:** Централизованная работа с состоянием приложения через Redux Toolkit с использованием слайсов (slices) для ингредиентов, заказов и авторизации.
*   **TypeScript:** Полная типизация приложения для повышения надёжности кода и удобства разработки.
*   **Защита маршрутов:** Реализована система Protected Routes, которая ограничивает доступ к разделам приложения в зависимости от статуса авторизации пользователя.
*   **Динамический интерфейс:** Drag-and-drop конструктор бургеров, модальные окна и реальное обновление данных.
*   **Модульные стили:** Использование CSS Modules для изолированных и поддерживаемых стилей.

## 📋 Функциональность

*   🍔 Сборка бургера перетаскиванием ингредиентов
*   👤 Регистрация и авторизация пользователя
*   🛡️ Защищённые маршруты для личного кабинета и истории заказов
*   📦 Оформление и отслеживание заказов
*   🔄 Real-time обновление статуса заказов через WebSocket

## 📋 Технологии и инструменты

*   **TypeScript**
*   **React**
*   **Redux Toolkit** (состояние приложения)
*   **React Router** (навигация)
*   **CSS Modules** (стилизация)
*   **WebSocket** (real-time обновления)

## 🔧 Установка и запуск

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/oostap1985/stellar-burgers.git
    ```
2.  Установите зависимости:
    ```bash
    npm install
    ```
3.  Запустите проект в режиме разработки:
    ```bash
    npm start
    ```
